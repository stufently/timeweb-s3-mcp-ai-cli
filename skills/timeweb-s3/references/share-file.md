# Обмен файлом

`s3_presign_get` выдаёт ссылку на разрешённый ключ; укажи срок не выше 604800 секунд. Ограничение профиля может требовать живой проверки: До 7 дней по AWS CLI документации; endpoint без собственного домена. standard/hot/cold — каталог тарифов бакета, не значения X-Amz-Storage-Class. Условия записи/удаления и PUT ObjectLock config требуют живой проверки.. Не записывай подпись в журналы. `s3_presign_put` может перезаписать объект и всегда требует подтверждения.
